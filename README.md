Simple Interest Calculator
## Simple Interest Calculator

The Simple Interest Calculator is a Bash-based application that calculates the simple interest based on the user's input values. The program asks the user to enter the principal amount, rate of interest, and time period, then calculates and displays the simple interest.

This project was created as an open-source project to demonstrate the use of Git and GitHub for version control, collaboration, and software development practices.
